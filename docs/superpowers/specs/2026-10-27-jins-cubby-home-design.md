# 主站主页设计（randomjin.top）

## 目标
在主域名 `randomjin.top` 上提供一个以 3D 十二面骰子为核心的主页：骰子面可悬停查看页面、点击进入；也能沿五边形交合处展开为平面网选择页面；另有「随机投掷」跳到任意配置页面。

## 技术栈
- Astro 静态站点 + TypeScript，无 UI 框架
- Three.js 渲染骰子，GSAP 时间线编排动画（position parameter / 标签 / defaults）
- 视觉 token 与 lab.randomjin.top 一致：背景 `#f5f5f5`、前景 `#1a1a1a`、次要文字 `#6b6b6b`、描边 `#c6c6c6`
- 小号文字使用等宽字体、大写、宽字距

## 结构
- `src/config/dice.config.ts`：唯一需要修改的配置。`DICE_PAGES`（12 个面 → 标题 / 链接，`url: null` 为未分配）、`ROLL_PAGES`（随机投掷的候选页面，与 12 个面解耦，整站页面多于 12 个时直接追加）
- `src/lib/dodeca.ts`：正十二面体几何、面编号（相对面之和 13）、邻接关系、双花形展开树与铰链参数、展开网尺寸
- `src/scripts/dice.ts`：场景、材质、数字贴图、相机适配、指针交互、投掷 / 展开 / 收起时间线
- `src/components/DiceStage.astro`：舞台、canvas 容器、DOM 面标签、结果区、tooltip
- `src/pages/index.astro` + `src/styles/global.css`：布局与黑白线框样式

## 骰子
- 12 个独立五边形 Mesh，白色填充 + 黑色描边，数字用 CanvasTexture 绘制
- 缩小的体积（相机按 `DIE_HALF` 适配），待机缓慢自转；悬停到面时暂停自转，保证目标稳定
- 可拖拽旋转

## 交互一：面悬停与点击
- 悬停已分配面：该面浅灰高亮，指针旁弹出黑底 tooltip 显示页面标题，光标变 `pointer`
- 点击已分配面：直接进入该页面
- 点击未分配面或空白：展开骰子

## 交互二：随机投掷
- 骰子先淡出全部数字变成纯白，再抛起 + 整圈旋转 + 四元数对齐、缓动减速
- 目标从 `ROLL_PAGES` 中随机，与骰子面编号无关
- 停止后在骰子下方淡入「Next · 标题」，约 1.1s 后跳转

## 交互三：展开 / 收起
- 展开树为双花形：根面 + 5 邻面（第一朵花），对置面 + 5 邻面（第二朵花），ring2 的一个面作为 bridge 接回第一朵花，只留一条缝，与参考图一致
- 每个面绕与父面共享边的中点、以边方向为轴旋转 `π − acos(−1/√5)`，链式矩阵累积；按 depth 错峰展开，父面先放平，动画中不重叠交错
- 展开时整体四元数归到根面、相机拉远适配平面网；数字淡出，未分配面转为浅灰
- 展开后：已分配面 hover 变黑底白字、可点击跳转；点击空白处（或 Esc）收起，无独立收起按钮
- 页面标题用 DOM 标签按面心投影定位，保证文字始终正向

## 响应式
- 画布自适应视口；展开时按平面网包围盒与视口比例计算适配距离

## 部署
- 构建通过后提交并推送到 `RandomJinJin/Jins-Cubby` 的 `main`，由已关联的 Vercel 项目自动部署到 `randomjin.top`
