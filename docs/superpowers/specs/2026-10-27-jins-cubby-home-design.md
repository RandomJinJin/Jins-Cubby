# 主站主页设计（randomjin.top）

## 目标
在主域名 `randomjin.top` 上提供一个以 3D 正二十面骰子为核心的主页：骰子面可悬停查看页面、点击进入；也能沿正三角形交合处展开为平面网选择页面；另有「随机投掷」跳到任意配置页面。

## 模型
主页使用正二十面骰子（20 个正三角形面，相对面编号之和 21）。此前实现的正十二面骰子（12 个正五边形面）保留在 `src/lib/dodeca.ts` 与 `DODECA_PAGES` 配置中，可随时切换回去。

## 技术栈
- Astro 静态站点 + TypeScript，无 UI 框架
- Three.js 渲染骰子，GSAP 时间线编排动画（position parameter / 标签 / defaults）
- 视觉 token 与 lab.randomjin.top 一致：背景 `#f5f5f5`、前景 `#1a1a1a`、次要文字 `#6b6b6b`、描边 `#c6c6c6`
- 小号文字使用等宽字体、大写、宽字距

## 结构
- `src/config/dice.config.ts`：唯一需要修改的配置。`DICE_PAGES`（20 个面 → 标题 / 链接，`url: null` 为未分配）、`DODECA_PAGES`（十二面骰子的 12 面映射，保留）、`ROLL_PAGES`（随机投掷的候选页面，与面解耦，整站页面多于面数时直接追加）
- `src/lib/icosa.ts`：正二十面体几何、面编号（相对面之和 21）、邻接关系、随机搜索不自重叠的展开树与铰链参数
- `src/lib/dodeca.ts`：正十二面体几何与双花形展开网（保留）
- `src/scripts/dice.ts`：场景、材质、数字贴图、相机适配、指针交互、投掷 / 展开 / 收起时间线
- `src/components/DiceStage.astro`：舞台、canvas 容器、DOM 面标签、结果区、tooltip
- `src/pages/index.astro` + `src/styles/global.css`：布局与黑白线框样式

## 骰子
- 20 个独立正三角形 Mesh，白色填充 + 黑色描边，数字用 CanvasTexture 绘制（面数由模型决定，几何按任意凸多边形三角剖分），字号约为面直径的 28%
- 缩小的体积（相机按 `DIE_HALF` 适配），待机缓慢自转；悬停到面时暂停自转，保证目标稳定
- 可拖拽旋转

## 交互一：面悬停与点击
- 悬停已分配面：反色——该面变纯黑、数字变白，指针旁弹出黑底白字 tooltip 显示页面标题，光标变 `pointer`
- 点击已分配面：直接进入该页面；点击未分配面不触发动作，避免与进入页面冲突
- 点击骰子以外的空白处：展开骰子；展开后再点击空白处收起（没有独立按钮）

## 交互二：随机投掷
- 骰子先淡出全部数字变成纯白，再抛起 + 整圈旋转 + 四元数对齐、缓动减速
- 目标从 `ROLL_PAGES` 中随机，与骰子面编号无关
- 停下后把正对镜头的那一面染黑标出落点，同时在骰子下方淡入「Next · 标题」，约 1.1s 后跳转

## 交互三：展开 / 收起
- 正二十面体：随机 DFS 生成覆盖 20 个面的生成树，用分离轴检测排除自重叠的候选，取包围盒最接近方形的一棵（约每面 3 个邻居，层级更深）
- 每个面绕与父面共享棱的中点、以棱方向为轴旋转到与父面共面（二十面体约 41.81°、十二面体约 63.435°），链式矩阵累积；按 depth 错峰展开，父面先放平，动画中不重叠交错
- 展开时整体四元数归到根面；画布改为固定铺满整个视口（四周不再被舞台框住），相机按 `NET_ZOOM` 只显示整张网的 52%，上下左右都超出屏幕
- 页头页脚作为透明覆盖层浮在画布之上，不遮挡模型；展开状态下点击穿透到画布，仅保留页头链接可点
- 展开后像地图一样：指针离开中心死区（45%）越靠近画面边缘，整张网越朝该方向平滑平移（指数阻尼），可查看屏幕外的面；指针离开画布时回正
- 数字淡出，未分配面转为浅灰；已分配面 hover 变黑底白字、可点击跳转；点击空白处（或 Esc）收起，无独立收起按钮
- 页面标题用 DOM 标签按面心投影定位（每帧随平移更新），保证文字始终正向
- 尺寸过渡：画布在展开瞬间铺满、收起结束瞬间缩回，画面尺寸靠相机距离按画布高度比例同帧换算（像素尺寸 ∝ 画布高 / 相机 z），骰子在切换帧不放大也不缩小；相机再以 GSAP 补间平滑推拉到展开 / 收起的适配距离，配合面的折叠与数字淡入淡出，整个过程没有跳变（不逐帧改画布尺寸，避免 `renderer.setSize` 重置缓冲造成空白帧）

## 响应式
- 画布自适应视口；展开时按平面网包围盒与视口比例计算适配距离

## 部署
- 构建通过后提交并推送到 `RandomJinJin/Jins-Cubby` 的 `main`，由已关联的 Vercel 项目自动部署到 `randomjin.top`
