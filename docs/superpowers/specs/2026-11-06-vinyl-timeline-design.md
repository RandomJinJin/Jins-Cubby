# /timeline — 黑胶唱片时间线

以“黑胶唱片机播放”为概念的个站时间线单页。左侧整张黑胶唱片（出血裁切），右侧年份 + 单条时间线卡片，滚轮逐条推进。

## 1. 页面结构

- 固定单页，`body { overflow: hidden }`（沿用站点默认）。
- 无 header，仅保留左上角 home 链接（与 randomjin.top header 同款：透明底、26px logo + 「今斤」）。
- 舞台 `.tl-stage` 铺满视口，`overflow: hidden` 负责视觉裁切；唱片图形本身完整，裁切只发生在页面边界（后续第二屏可复用同一份图形）。

## 2. 唱片定位（CSS 变量，可独立调整）

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `--rec-d` | `113vh` | 直径 ≈ 113% 视口高 |
| `--rec-x` | `13vw` | 圆心 X |
| `--rec-y` | `61vh` | 圆心 Y |

推导结果：右边缘 ≈ `44.8vw`，顶部留白 ≈ `4.5vh`，左侧出血 ≈ `36.3vh`，底部出血 ≈ `17.5vh`；视口左下角完全落在圆内，不露背景。

## 3. 唱片绘制（viewBox 1000×1000，圆心 500,500）

- 基底：径向渐变 `#1e1e21 → #151518 → #0d0d0f → #09090a`，叠加内阴影；外层向下浅投影（`22px 34px 54px -12px rgba(0,0,0,.28)`）。
- 纹路：31 条银灰细环（`opacity .05–.12`，`width .6–1.4`）+ 7 条低透明暗环。
- 随机装饰弧段：26 条，半径 `198–490`、弧长 `6°–36°`、线宽 `.6–2.0`、`opacity .05–.13`；避开 1–3 点钟反光区（`-80°~2°`）与年轮 ±8。这些弧段是断续的，唱片旋转时颗粒感明显。
- 反光：仅集中在右上 1–3 点钟，11 条弧形高光（半径 232–486）+ 5 条暗带，圆头收口，无大块白色渐变、无直线高光。
- 中心 label：直径 = 唱片直径 `36%`，与唱片同心；logo 铺满整个 label（`object-fit: cover`）。

## 4. 年份年轮

- 年轮按年份升序由内向外，半径 `315 → 482` 等差分布（4 年时 315 / 370.7 / 426.3 / 482）。
- 每条年轮是一圈可交互的细环：`hover` 变亮、鼠标旁出现年份 tooltip（不 hover 时无任何年份文字）；`click` / Enter 跳到该年第一条。
- 非年份的装饰纹路全部 `pointer-events: none`。

## 5. 唱针（独立 SVG，viewBox -200 -200 1400 1400，唱片单位）

- 圆形转轴壳：`(974, 156)`，`r=44`，象牙白径向渐变 + 内环 + 轴心 + 深色中心点。
- 细直臂：`9` 宽，横向渐变做出圆柱高光，从转轴中心垂下。
- 唱头：梯形白色陶瓷壳，`rotate(-9°)`，右侧有内凹阴影面。
- 针尖：2px 细针 + 针点，落在当前年份年轮上。
- 层 `pointer-events: none`，`drop-shadow` 柔和投影，不遮挡年轮交互。
- 转角由几何反解：针尖在 0° 时距圆心 482（= 2026 年轮），转动 `φ` 后落在半径 `r`。实测 2026 `0°` / 2025 `8.7°` / 2024 `19.5°` / 2023 `31.7°`。

## 6. 右侧内容

- 内容区 `left: 49vw; right: 4vw`。
- 年份：`top: 22.1%` + `translateY(-50%)`，与转轴圆心同一水平中线；字号 `clamp(56px, 7vw, 120px)`；**黑色描边 + 透明填充**（`-webkit-text-stroke`，镂空）。
- 单条卡片：`top: 47%`，无边框、无底色、无分隔线；内容为日期 / 标题 / 描述 / 可选图片 / `当前 / 总数`。
- 无底部提示文字。

## 7. 交互

- 滚轮（含触控板）每次切换一条，节流 520ms；边界不循环。
- 触屏上下滑动 > 46px 切换；键盘 ↑↓ / PageUp / PageDown。
- 同年内切换只换卡片；跨年时：更新年份、唱针旋转、当前年轮高亮、唱片额外旋转 6°。
- 卡片切换：旧卡 `opacity→0` 0.2s，新卡 `opacity 0→1 + y 10→0` 0.38s。
- `prefers-reduced-motion: reduce` 时全部时长归零。

## 8. 响应式

- ≤ 820px：唱片改为 `96vw` 直径、圆心 `50vw / 30dvh`，缩到上方；内容区下移到 `top: 60dvh`，年份字号缩小；唱针随唱片等比缩放并保留在右上。
- ≤ 820px 及窄屏不再依赖 hover，改用滑动/键盘。

## 10. 初始化策略

- 默认从最早年份的第一条开始，滚轮向下 = 向未来推进；改成最新年份只需调整初始索引。
