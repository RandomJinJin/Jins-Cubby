## 炫彩遮罩作用域收窄：只作用于骰子

**需求**：只给骰子添加炫彩遮罩，展开的骰子地图也保留，主页其他元素无炫彩效果。

### 核心结论：作用域由「隔离混合组」决定

`mix-blend-mode` 只在**最近的隔离组（isolated group）内**混合。
遮罩原本挂在 `body` 下 → backdrop 是整个视口 → 黑色按钮、页脚文字、tooltip 全被染色。

**解法**（三处改动）：
1. 遮罩挂进 `.canvas-host`（`src/iridescence/index.ts` 新增 `options.container`）
2. `.canvas-host` 加 `isolation: isolate` —— 建立隔离组
3. `.canvas-host` 加 `background: var(--bg)` —— **必须不透明**，否则透明区域 backdrop 为空，遮罩退化成实色圆斑

展开的骰子地图用同一块画布，自动保留炫彩。

### 挂载点跟着作用域走
遮罩改由 `src/components/DiceStage.astro` 挂载（画布宿主），不再放全局布局。
副产品：about/friends 页连遮罩代码都不加载了。

### 测量教训（重要）
只比截图哈希会误判。骰子自转的抗锯齿抖动产生 556 个灰阶差异像素，看着像"远处描边被染色"，实际饱和度差 = 0。
必须区分**彩色差异**（染色，sat > 20）与**灰阶差异**（抖动）。判定标准：彩色像素数 = 0。

实测：黑色按钮 / 页头文字 / tooltip / 展开图远处描边 / 悬停面 —— 彩色像素全部为 0；
画布内黑块 42195 个彩色像素（炫彩正常）。
